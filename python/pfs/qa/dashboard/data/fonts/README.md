# Fonts embedded in the run report

The run report carries its two typefaces inside the page (`runReport._fontFaces`), so it looks the same wherever
it is opened and fetches nothing.

| File | Typeface | Licence |
|---|---|---|
| `Inter-latin.woff2` | Inter, variable weight, Latin subset as Google Fonts serves it (v20) | SIL Open Font License 1.1, `Inter-OFL.txt` |
| `SpaceGrotesk-latin.woff2` | Space Grotesk, variable weight, Latin subset as Google Fonts serves it (v22) | SIL Open Font License 1.1, `SpaceGrotesk-OFL.txt` |
